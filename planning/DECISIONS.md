| D-13 | Every local secret lives in **one file, the repo-root `.env`** (git-ignored). Apps reference it rather than keeping their own: `web/next.config.ts` loads it with `@next/env` `loadEnvConfig`, and ai-service loads it by path. There's no `web/.env.local`. Deployed values are still set in Vercel, `convex env set` and on Brev. The root `.env.local` that `convex dev` writes holds only non-secret deployment pointers (`CONVEX_DEPLOYMENT`, `CONVEX_URL`) and is loaded too. Locally the Next server process therefore holds every root secret: only `NEXT_PUBLIC_*` values may ever reach the browser, and `next.config.ts` must never get an `env:` block. Story 26 of the V0 spec ("AI keys only on the Brev box") is read as: never in the repo, in `web/` or in client code; on Brev in deployment; and in the root `.env` for local runs such as the #9 smoke. Python loads only what it needs, and `configure_tracing` copies only `LANGSMITH_*` into `os.environ`. | operator |

Strings survive only under structural keys (ids, trade, verdict, status and similar), URLs are always redacted, and errors keep only the exception type. Implements ADR-13. | `ai-service/README.md` |
