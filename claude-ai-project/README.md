# Claude.ai Project setup (not code)

Use a Claude.ai Project as your **planning and thinking partner** alongside Claude Code, which does the building. Use the Project for pitch prep, Swahili copy review, rubric writing, reading review reports, and deciding what to cut when time runs short.

## Steps
1. Go to claude.ai and create a new Project called **Smart Fundis**.
2. **Custom instructions:** paste the whole of `project-instructions.md`.
3. **Project knowledge:** upload these files:
   - `docs/PRD.md`
   - `AGENTS.md`
   - `knowledge-brief.md` (from this folder)
   - over build day, add the latest `docs/handoff/*.md` and `docs/reviews/*.md` so the Project stays current
4. Use the starter prompts in `starter-prompts.md`.

Keep the Project in step with the repo. When the PRD changes, re-upload it.
