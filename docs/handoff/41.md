## What changed
**Convex**
- `convex/reviews.ts` (new):
  - `queue`: the `awaiting_review` Assessments in the caller's approved Trades, oldest first, at most 50. It never includes the caller's own Assessments or a Demo Fundi's. A row carries the Trade and Task names and the safety-flag count. It has no AI Verdict (automation bias), no video and no phone. Guard: `requireExpert`.
  - `detail`: one Assessment for an Expert who `canDecide` on it. It returns the Rubric items, the Liveness code and what the AI read, the Observations, the Verdict, strengths, gaps, safety flags and feedback. It has no confidence number. It is **the only query that returns a video URL**, and only while the status is `awaiting_review` or `appealed`. It returns `null` for a missing Assessment or a refused caller, so existence doesn't leak. Guard: `requireStoredUser`, then `canDecide`.
  - `decide`: approve, reshoot or reject an `awaiting_review` Assessment. In one transaction it writes the status, one `reviews` row and one `auditLog` row. The note is trimmed, required for reshoot and reject, optional for approve, and at most 1000 characters. The errors are `forbidden` (one generic code for a missing Assessment and every `canDecide` refusal), `invalid_status`, `note_required` and `note_too_long`.
- `convex/lib/auth.ts`: `getActiveExpert` and `canDecide` (spec §4). It refuses:
  - the Assessment's own Fundi, Admins included;
  - a non-Expert or an inactive Expert;
  - a Trade the Expert isn't approved for;
  - the original decider of an appealed Assessment;
  - a Demo Assessment.
- `convex/lib/assessmentNames.ts` (new): `namesFields` and a memoised `nameLookup` for Trade and Task names.
- `convex/assessments.ts`: `listMine` returns `decidedAt` (from the latest review) and `expertNote` (for reshoot and rejected only, never on approval and never who decided). `get` no longer returns `videoUrl`.

**Web**
- `web/app/(site)/expert/`: `page.tsx` and `expert-guard.tsx` (the page guard), and `review-queue.tsx` (Trade: Task, upload date and safety-flag count per row, with no Verdict word).
- `web/app/(site)/expert/[assessmentId]/`:
  - `review-detail.tsx`: the video, with `controlsList="nodownload noremoteplayback"` and `disablePictureInPicture`. It shows "deleted", "couldn't load" or "closed" depending on `videoDeletedAt` and the status. It also shows the Liveness code against what the AI read, each Rubric item's Observation, and the "AI suggestion — you decide" panel.
  - `decision-form.tsx`: no decision is pre-selected. Submit stays disabled until one is chosen. The approval note is labelled "for the record — not shown to the Fundi". The error is linked to the note by `aria-describedby`.
  - `error.tsx`: a malformed id shows "not available".
- `web/app/(site)/fundi/assessment-list.tsx`: the Badge line "Verified by Smart Fundis — <Trade>: <Task> · <date>" on an approved Assessment, and the Expert's note on a rejection or an Expert-requested reshoot.
- `web/lib/review-errors.ts`: `DECIDE_ERRORS`, typed so an unmapped server code fails to compile. `web/lib/page-guard.ts` and `dashboard-route.ts`: `BUILT_ROLE_ROUTES.expert = true`, so `/dashboard` sends Experts to `/expert`.
- `web/messages/en.json`: the `ReviewQueue`, `ReviewDetail` and `DecisionForm` namespaces, plus `AssessmentList.badgeLine` and `expertNoteLabel`. **English only (D-64).**
- `web/eslint.config.mjs`: an `_` prefix marks a deliberately unused arg or var.

## For the Architect (rulings and deferred items)

## Contracts / interfaces introduced
- `api.reviews.queue({})` returns `{ assessmentId, _creationTime, tradeSlug, tradeName, taskSlug, taskName, safetyFlagCount }[]`.
- `api.reviews.detail({ assessmentId })` returns `{ _id, _creationTime, status, tradeSlug, tradeName, taskSlug, taskName, rubricItems, livenessCode, livenessRead?, livenessCheck?, observations, verdict?, strengths, gaps, safetyFlags, feedbackEn?, fallbackModel?, videoUrl: string | null, videoDeletedAt? } | null`.
- `api.reviews.decide({ assessmentId, decision: "approve" | "reshoot" | "reject", note? })` returns `null`, or throws `ConvexError({ code: "forbidden" | "invalid_status" | "note_required" | "note_too_long" })`.
- `api.assessments.listMine` gains `decidedAt?` and `expertNote?`. `api.assessments.get` has no `videoUrl`.
- `canDecide(ctx, userId, assessment)` returns `{ ok: true } | { ok: false, reason }` in `convex/lib/auth.ts`.
