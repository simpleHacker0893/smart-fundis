## How to verify
1. `pnpm install` at the repo root, then `pnpm typecheck && pnpm lint && pnpm test && pnpm build`.
2. `pnpm dev`, then open http://localhost:3000 in Chrome DevTools device mode at 360 px. Check that the console is empty and nothing scrolls sideways.
3. `node scripts/check-env-example.mjs` prints `OK: 16 PRD §7 names`.
