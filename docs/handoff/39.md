## What changed
**HTTP (ADR-9: Brev calls out, no inbound port)**
- `convex/http.ts` (new) holds both routes. Each one checks the bearer secret, narrows the JSON body, calls one internal mutation and maps the result to a status code. The routes never log a request or a job.
  - `POST /ai/claim` returns **401**, **400**, **204** or **200** with the §6 job.
  - `POST /ai/callback` returns **401**, **400**, **409** for a stale callback, or **200** `{ status }`.

**State changes (each one is a single transaction)**
- `convex/aiJobs.ts` (new):
  - **`claim`** moves the oldest `queued` Assessment to `analyzing` with `attempts + 1`, `claimedAt` and `claimedBy`, and returns the job.
    - A queued row whose video, Rubric or Trade is gone becomes `failed`, and the next row is claimed.
  - **`callback`** handles the three outcomes:
    - `result` → `awaiting_review`, after the server-side hard rules;
    - `reshoot` → `reshoot`, with the reason;
    - `error` → `queued` while attempts < 2, else `failed`.

    It refuses a callback, writing nothing, in these cases:
    - **`stale` (409):** the Assessment is not `analyzing`, the `attempt` differs, the row was deleted, or the id is garbage or another table's id.
    - **`unknown_item`, `duplicate_item` or `out_of_range` (400).**
  - **`requeueStale`** looks for `analyzing` rows claimed more than 10 minutes ago. It sets one to `queued` on attempt 1 and to `failed` once attempts reach 2, working in batches of 100.
- `convex/crons.ts` (new) runs `requeueStale` every minute ("requeue stale AI claims").

**Helpers**
- `convex/lib/aiSecret.ts` (new): `isWorkerAuthorized`.
  - Both the token and the secret are hashed with SHA-256, then compared byte by byte in constant time.
  - An unset or empty `AI_SHARED_SECRET` refuses every request.
  - The scheme must be exactly `Bearer `.
- `convex/lib/conforms.ts` (new): `conforms(validator, value)`, a type guard that checks untrusted JSON against a Convex validator.
  - It rejects missing fields, extra fields (own properties only, so `toString` and `constructor` are rejected too) and non-finite numbers.
  - The validator stays the single definition of each body's shape.
- `convex/lib/aiContract.ts` (new):
  - Validators: `claimBodyValidator`, `jobValidator` and `callbackBodyValidator`.
  - Limits and timings: `MAX_*`, `CLAIM_TIMEOUT_MS`, `MAX_ATTEMPTS` and `CLAIM_SCAN`.
  - **`applyHardRules` (ADR-11):**
    - Liveness is `yes` only when the worker says `yes` **and** the digits it read equal the stored Liveness code.
    - A safety item is flagged when any of its Observations is `no` or `unclear`, or it has none.
    - A `pass` with liveness that isn't `yes`, or with any flag, becomes `needs_review`. A Verdict is never raised.
  - **`hasDuplicateItemId`.**
  - **`fillMissingObservations`:** a Rubric item with no Observation is stored as `unclear` (§6 rule 2).
  - **`resultInBounds` and `errorCodeInBounds`:**
    - `confidence` must be in [0, 1], and `latencyMs` and `timestampS` must be at least 0.
    - Lists hold at most 20 items. Evidence and feedback hold at most 2000 characters, and `model` and `errorCode` at most 200.
    - `safetyFlags` must be Rubric item ids.
- `convex/lib/validators.ts`:
  - `reshootReason.sw` is now optional (D-64).
  - Adds the `Observation`, `Verdict` and `LivenessCheck` types.
- `convex/schema.ts`: `assessments.fallbackModel` is now `v.optional(v.boolean())`. It was a string; the spec and US-4.6 say boolean.
- `convex/_generated/api.d.ts`: regenerated, adding `aiJobs`, `http`, `crons` and the lib modules.

## Contracts / interfaces introduced
- **Both endpoints** need the header `Authorization: Bearer <AI_SHARED_SECRET>`, with `Bearer` exactly as written (case-sensitive).
- **`POST /ai/claim`**, body `{ "workerId": string (1–100 chars) }`:
  - **204**, with an empty body, when nothing is queued.
  - **200** with `{ assessmentId, attempt, videoUrl, trade:{slug,name}, task:{slug,name}, rubric:{id,version,items:[{id,text,safety}]}, livenessCode }`.
  - **400** for a bad body; **401** for a bad secret.
- **`POST /ai/callback`**, body `{ assessmentId, attempt, outcome, … }`:
  - `outcome: "result"` comes with:
    - `observations[{itemId,result:"yes"|"no"|"unclear",evidence,timestampS}]`;
    - `liveness:{read:string|null, check:"yes"|"unclear"}`;
    - `verdict:{verdict:"pass"|"needs_review"|"fail", confidence, strengths[], gaps[], feedbackEn, feedbackSw?}`;
    - `safetyFlags[]` (Rubric item ids), `model`, `fallbackModel: boolean` and `latencyMs`.
  - `outcome: "reshoot"` comes with `reason:{code:"too_short"|"too_long"|"low_res"|"too_dark", en, sw?}`.
  - `outcome: "error"` comes with `errorCode` (at most 200 characters).
  - Responses:
    - **200** `{ status }`, the new Assessment status;
    - **409** `{ error: "stale" }`;
    - **400** `{ error: "bad_request" | "unknown_item" | "duplicate_item" | "out_of_range" }`;
    - **401**.
- **Internal:** `internal.aiJobs.claim`, `internal.aiJobs.callback` and `internal.aiJobs.requeueStale`. The cron is named "requeue stale AI claims".

## Env vars / manual setup
- **`AI_SHARED_SECRET`** must be set on each Convex deployment with `pnpm exec convex env set AI_SHARED_SECRET <value>`, using a different value for dev and prod (spec §3). The worker reads the same value from the root `.env`. Until it is set, both endpoints return 401 by design.
- **The functions are already on the dev deployment.** `pnpm exec convex codegen` pushed them there while the types were generated. Nothing was deployed to prod.
- **Before the prod deploy:** confirm that no `assessments` row holds a *string* `fallbackModel`, or the schema push will fail. Nothing on this branch or on main ever wrote one.

## Open issues / blockers
- **`queued → failed` for an unclaimable row** (its video, Rubric or Trade is missing) is not a row in the §5 status table. It was done so a broken row can't block the head of the queue. Please confirm, or add the row to the spec. Owner: architect.
- **AGENTS.md rule 3** ("every Convex function checks identity and role"): the `aiJobs` internal mutations rely on the HTTP bearer check, because a Brev worker has no Clerk identity (ADR-9). Please confirm the exemption. Owner: architect.
- **`timestampS` is not checked against the video's length.** Convex doesn't store the duration, so `rules.py` keeps that check (§6 rule 5). Owner: ai-pipeline (V2).
- **CLAIM_SCAN = 5:** if the 5 oldest queued rows are all broken, that poll fails them and returns 204, and the next poll claims the good row. Each poll is a mutation, so many pollers would contend. That is fine with one worker. Owner: convex (later).
- **Deferred polish:** one private function per `callback` outcome, and a named type for the `applyHardRules` input. Owner: convex.
