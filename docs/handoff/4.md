## What changed
- `convex/schema.ts`: `users` has clerkId, email, name, and optional phone, county and isDemo, with index `by_clerkId`. **`clerkId` holds `identity.tokenIdentifier`** (D-16). `email` is display-only, stored trimmed and lowercased.
- `convex/auth.config.ts`: the Clerk provider, `applicationID: "convex"`. It throws a clear message if `CLERK_FRONTEND_API_URL` is unset.
- `convex/lib/auth.ts`:
  - `requireUser(ctx)` returns `{identity, user}` or throws `Not authenticated`.
  - `getRoles(ctx, caller)` returns `{base: "none", expert: false, admin}`.
  - **Admin = email on `ADMIN_EMAILS` (trimmed, case-insensitive) AND `email_verified`** (ADR-18).
- `convex/users.ts`:
  - `store` is an idempotent upsert from the token, with no arguments.
  - `me` returns **`{ user, roles }`** (spec §4). It takes no arguments, throws when unauthenticated, and only ever returns the caller's own row.
- Root: `vitest.config.mts` (edge-runtime), `typecheck:convex` and `test:convex` chained into `pnpm typecheck` and `pnpm test`, and devDependencies `vitest`, `convex-test`, `@edge-runtime/vm`, `vite` and `@types/node@^22`.
- `web/components/convex-client-provider.tsx`: `ConvexProviderWithClerk`. **When no URL is set, it renders the children without Convex and warns**, so a build or the public pages never crash.
- `web/components/store-user-on-auth.tsx`: calls `users.store` once per signed-in session, on every page. It retries at the next sign-in if the call fails.
- `web/app/dashboard/`: the page keeps `auth.protect()` (D-15). `signed-in-as.tsx` shows `me.user.email`, falling back to the Clerk email.
- `convex/_generated/` is committed.
- `planning/DECISIONS.md`: **D-16**.

## Contracts / interfaces introduced
- `api.users.store()` returns `Id<"users">`.
- `api.users.me()` returns `{ user: Doc<"users"> | null, roles: { base: "fundi" | "none", expert: boolean, admin: boolean } }`.
- `requireUser(ctx)` returns `{ identity, user }`. `getRoles(ctx, caller)` returns the roles. Export: `rolesValidator`.

## Env vars / manual setup
- Convex dev: `CLERK_FRONTEND_API_URL`, `ADMIN_EMAILS` and `AI_SHARED_SECRET` (set).
- Local: the root `.env` / `.env.local` provide `CONVEX_URL`, which `next.config.ts` copies to `NEXT_PUBLIC_CONVEX_URL` (D-13).
- Vercel (#6): `NEXT_PUBLIC_CONVEX_URL` must be set, or the dashboard has no Convex, although the public pages still build.
